# День 27. Интеграция локальной LLM в приложение

Цель дня — использовать локальную модель из настоящего приложения: отправить
пользовательский запрос, получить ответ и показать его в чате без облачной модели.
Приложение — TalkLoop, экран — существующая вкладка «Агент».

Основа уже подготовлена в [Дне 26](day26-local-llm.md): Ollama запущена на Mac,
Qwen3.5 9B скачана, локальный HTTP-клиент и три запроса проверены.
Этот PR использует тот транспорт и добавляет мобильное подключение.

## Шаг 1. Добавить выбор источника ответов

В «Агент → Настройки → Модель агента» доступны Claude и «Ollama · локально».
В локальном режиме указываются адрес Ollama и название скачанной модели.

**Для чего:** выбирать модель средствами приложения. Заголовок агента показывает
активный режим, например `Локально на Mac · qwen3.5:9b`.

Реализация: `AgentConnection`, `AgentConnectionCard`, платформа создания клиента.

## Шаг 2. Соединить эмулятор с Mac

Для Android Emulator:

```text
http://10.0.2.2:11434
```

Для iOS Simulator:

```text
http://127.0.0.1:11434
```

**Для чего:** обратиться к Ollama на компьютере, где запущен эмулятор. Android
использует специальный адрес хоста: его собственный `127.0.0.1` указывал бы
на Android, а не на Mac. Локальный клиент обходит системный HTTP-прокси.
Эти адреса для эмуляторов не являются готовыми настройками настоящего телефона.

## Шаг 3. Подключить транспорт к существующему агенту

`App` создаёт `OllamaLlmClient`, передаёт его в `AgentRuntime` и создаёт
`TalkLoopAgent` с выбранной моделью и рабочим окном 16 384 токена.

**Для чего:** сохранить системные инструкции, профиль, инварианты и историю
в существующей логике агента. Генерация проходит через `LlmClient` и
`TalkLoopAgent`; UI показывает результат агента.

Локальный режим не требует ключа Claude. При ошибке Ollama приложение сообщает
об ошибке, сохраняет неотправленный текст для повтора и не вызывает Claude.
При выборе Ollama служебная память RAG и проверка цитат также используют её.
Отдельный полноценный RAG-прогон с локальной моделью ещё не выполнялся.

## Шаг 4. Проверить доступность и применить модель

1. На Mac оставить Ollama запущенной и убедиться, что `qwen3.5:9b` уже скачана.
2. В настройках агента выбрать «Ollama · локально».
3. Нажать «Проверить подключение».
4. Дождаться `Ollama доступна · qwen3.5:9b скачана`.
5. Нажать «Использовать выбранную модель» и скрыть настройки.

**Для чего:** до первого диалога проверить `/api/tags` и наличие нужной модели.
Проверка не скачивает веса и не запускает генерацию. Если модели нет, приложение
подсказывает команду `ollama pull` для Mac.

## Шаг 5. Отправить запрос и показать ответ

В проверке Android-эмулятора отправлено:

```text
Translate: I am learning English.
```

Ответ Qwen отображён в чате:

```text
I am learning English. (Перевод на русский язык)

Я изучаю английский.
```

**Для чего:** проверить весь путь от пользовательского ввода до ответа в
интерфейсе приложения. Запрос проходит на Mac через локальный API Ollama.

## Шаг 6. Сохранить выбор и продолжить после перезапуска

Android хранит провайдера, адрес и имя модели в настройках приложения. История
остаётся в существующем постоянном хранилище TalkLoop.

**Для чего:** после закрытия и повторного запуска продолжать диалог с выбранной
моделью. В эмуляторе проверен полный перезапуск: сохранились локальный режим,
переписка и полученный ответ. В iOS проверена компиляция; постоянное сохранение
выбора провайдера в этой реализации добавлено только на Android.

## Интернет и локальная связь

Модель работает на Mac. Приложение в эмуляторе связывается с Mac по локальному
адресу. Для обычного чата скачанной Qwen внешний интернет не нужен, но связь
с сервером Ollama нужна. Полностью автономный запуск модели на телефоне
в этот PR не входит.

При демонстрации можно отключить внешний интернет на Mac, сохранив связь
эмулятора с ним, и отправить новый запрос. Полное закрытие сервера Ollama должно
дать ошибку соединения при следующем запросе. Это ручной сценарий проверки,
автоматическое отключение интернета и сервера не выполнялось.
Внешние источники MCP, например погода, могут требовать интернет независимо
от того, какая модель выбрана. Для демонстрации обычного локального чата
следует отключить RAG и MCP.

Отсутствие свежих новостей или ответ модели на вопрос «кто ты?» не доказывают
локальность. Облачная Claude в TalkLoop тоже не получает веб-поиск автоматически.
Другие учебные вкладки продолжают использовать Claude; данный PR подключает
Ollama именно к вкладке «Агент».

# День 30. Агент TalkLoop → приватная модель на VPS

## Что запускается

Модель `qwen2.5:0.5b` работает в Ollama на VPS AdminVPS: Ubuntu 24.04,
x86_64, 1 vCPU, 2 ГБ RAM. Агент TalkLoop отправляет запросы напрямую на
`https://89.40.70.118:18443/api/chat`. Mac для генерации и SSH-туннель не нужны.
Телефону или эмулятору нужен сетевой доступ к VPS.

Ollama слушает только `127.0.0.1:11434`. Наружу выходит отдельный HTTPS-сервис
с ключом Bearer. Он сохраняет нативный формат Ollama: system prompt, историю,
JSON schema, счётчики токенов. Это позволяет использовать существующего агента
TalkLoop без перехода на облачную модель.

## Ограничения

- Разрешена только скачанная `qwen2.5:0.5b`; скачивание и облачные модели через API недоступны.
- Один активный запрос генерации; второй получает HTTP 429 и Retry-After.
- Шесть принятых запросов генерации за скользящие 60 секунд на весь сервис.
- `num_ctx` не больше 8192; `num_predict` не больше 256; один поток CPU.
- Тело запроса до 32 КиБ, до 32 сообщений. Превышение контекста — HTTP 413 до обращения к модели.
- Контекст проверяется консервативно по UTF-8 байтам, с резервом под ответ и JSON schema.
  Это оценка, а не точный токенизатор; длинный диалог может быть отклонён раньше реального лимита модели.
- Существующие ограничения Ollama: MemoryHigh=1G, MemoryMax=1200M, CPUQuota=60%,
  одна загруженная модель, одна параллельная генерация, очередь до двух запросов.
- Сервис HTTPS: MemoryMax=96M, CPUQuota=10%, максимум восемь соединений.

Окно 2048 подходило для отдельного короткого вопроса, но не вмещает инструкции
агента, правила и слои памяти при консервативной проверке. Профиль VPS использует
8192 и короткие ответы. Долгая история, активная задача и RAG могут превысить этот
бюджет. Первая проверка — в новой задаче без RAG и MCP. Память и инварианты
автоматически не удаляются. Возможности маленькой модели нужно оценивать отдельно.

## Установка на VPS

Предварительно проверены свободные TCP 80 и 18443; UFW inactive. Порт 80 нужен
для проверки владения IP и дальнейшего продления сертификата. Если у провайдера
есть внешний firewall, в нём должны быть доступны TCP 80 и 18443. Порт Ollama
11434 наружу открывать не нужно. Скрипт не меняет firewall или службы VPN.

В новой вкладке Терминала **на Mac**:

```bash
scp -r /Users/a1/AndroidStudioProjects/TalkLoop/tools/day30 root@89.40.70.118:/root/talkloop-day30
```

В SSH-консоли **на сервере**:

```bash
bash /root/talkloop-day30/install.sh 89.40.70.118
systemctl status talkloop-private-ai --no-pager
systemctl list-timers talkloop-cert-renew.timer
```

HTTPS использует доверенный сертификат Let's Encrypt для IP. Certbot >=5.4
поддерживает такие сертификаты; профиль shortlived действует шесть дней.
Таймер проверяет продление каждые шесть часов, deploy hook копирует сертификат
с ограниченными правами и перезагружает TLS без остановки текущего запроса.
[Официальная инструкция Let's Encrypt](https://letsencrypt.org/2026/03/11/shorter-certs-certbot).

Ключ создаётся только на VPS, в `/etc/talkloop-private-ai/token`, и не выводится
установщиком. Посмотреть его для вставки в приложение:

```bash
cat /etc/talkloop-private-ai/token
```

Не отправляй ключ в чат, скриншоты или Git. В Android он хранится в зашифрованном
виде с ключом Android Keystore; в iOS — в Keychain. Проверка сертификата HTTPS
в приложении остаётся стандартной. Перенаправления запрещены.

## Подключение приложения

1. Агент → Настройки → Ollama · своя модель.
2. Нажать «День 30 · VPS · Qwen 0.5B». Кнопка заполняет адрес, модель и параметры.
3. Вставить ключ в «Ключ приватного сервиса».
4. «Проверить подключение» → «Сохранить и применить».
5. Начать новую задачу для короткой проверки. Отправить три разных вопроса.

Настройки не переключают остальные лабораторные вкладки: профиль относится
к главному агенту, включая его вызовы модели для RAG при включении RAG.

## Проверки и статус

По скриншоту сервера подтверждены: Ollama active, модель скачана, HTTP-запрос
к локальному Ollama вернул «Париж.». Первый запрос занял 6.366 с с загрузкой
модели; в памяти модель занимала 456 МБ при контексте 2048. После запроса
доступно 1.1 ГиБ RAM. Столбец «100% CPU» в ollama ps обозначает CPU backend.
Эти измерения ещё не характеризуют генерацию с полным prompt агента и окном 8192.

Автоматические проверки: нативный API и ключ HTTPS, три коротких хода агента с
инвариантами/памятью в бюджете 8192, сборка Android и компиляция iOS; девять
тестов шлюза, включая настоящее тестовое HTTPS-соединение, отказ без ключа,
сохранение истории/schema, rate limit, занятость и ограничения контекста.
Тестовые ответы подставные: это проверка интеграции, не качества VPS-модели.

После установки проверить реальный внешний API **на Mac**, введя ключ скрыто:

```bash
python3 /Users/a1/AndroidStudioProjects/TalkLoop/tools/day30/check_service.py https://89.40.70.118:18443
```

Скрипт выводит три ответа и задержки, затем результаты параллельных запросов,
ограничений контекста и частоты. Ключ в вывод не входит. При уже исчерпанном
лимите нужно дать минутному окну освободиться и повторить проверку.
12 октября 2026 подтверждены установка сервиса на VPS (`active`,
`Ready: https://89.40.70.118:18443`, скриншот пользователя) и внешний HTTPS
с Mac: запрос `/health` с обычной проверкой сертификата, без ключа и без proxy,
вернул HTTP 401. Это подтверждает доступность защищённого внешнего API и
отказ неавторизованному клиенту.

После установки пользователь подтвердил успешное подключение приложения с
ключом и выполнение проверок: «Все протестил все ок». Агент TalkLoop использует
приватный сервис по внешнему IP; модель работает на VPS.

Дополнительно проверено с Mac: `/api/tags` без ключа возвращает HTTP 401,
прямое соединение с внешним портом Ollama 11434 отклоняется. В эмуляторе ключ
сохранён только в зашифрованном поле настроек. В текущих файлах проекта и
доступной локальной истории Git реальные ключи и пароли не обнаружены.

Автоматические проверки подтверждают ограничения сервиса и восстановление
после сбоя Ollama. Отдельные численные замеры RAM при окне 8192 и полный
вывод нагрузочного скрипта с VPS в этом отчёте не зафиксированы.

Диагностика на сервере:

```bash
journalctl -u talkloop-private-ai -n 40 --no-pager
ollama ps
free -h
```

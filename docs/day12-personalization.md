# День 12. Персонализация ассистента

## Модель профиля

`UserProfile` хранится в каталоге профилей как отдельная специализированная часть
долговременной памяти:

- `id` и необязательное отображаемое имя идентифицируют пользователя;
- `language` задаёт язык ответа по умолчанию;
- `style` описывает тон и уровень подробности;
- `format` задаёт желаемую структуру;
- `constraints` содержит постоянные ограничения.

Профили не смешиваются с историей, рабочими данными, решениями или знаниями.
Каталог и ID активного профиля переживают `startNewTask`, пересоздание агента и
перезапуск приложения. Профиль с тем же ID обновляется атомарно. Можно переключиться
в режим «Без профиля» и позже вернуться к сохранённому варианту либо удалить только
один профиль, не затрагивая остальные слои.

## Как профиль подключается к запросу

Перед основным вызовом модели агент выбирает активный профиль и собирает контекст
выбранной стратегии (summary, facts, ветку или memory layers), а затем добавляет структурированный блок
`user_profile` в system prompt. Этот путь находится внутри `TalkLoopAgent.respond`,
поэтому UI и вызывающий код не должны повторять настройки в каждом сообщении.

Приоритет поведения:

1. явная просьба в текущем сообщении;
2. сохранённый профиль как настройка по умолчанию;
3. базовое поведение агента.

Пустые поля не додумываются. Значения экранируются перед помещением в размеченный
блок. Агенту также указано не рассказывать о профиле без необходимости.

## Проверка

Автономные тесты без сети подтверждают, что:

- один запрос получает разные ответы для краткого и подробного профилей;
- профиль присутствует в system prompt каждого следующего запроса;
- явная просьба о формате на текущем ходу важнее сохранённого формата;
- значения нормализуются, профиль переживает новую задачу и перезапуск;
- профиль сериализуется вместе с остальной памятью и удаляется независимо.
- несколько профилей сохраняются одновременно, переключаются по ID и восстанавливаются;
- режим без профиля не добавляет `user_profile`, но сохраняет каталог для будущего выбора.

Живой прогон на `claude-haiku-4-5` также показал причинную разницу. Профиль
руководителя дал короткий план из трёх пунктов и два кратких риска. Профиль
начинающего разработчика объяснил термины, разбил материал на учебные секции и
добавил пример. Во втором вопросе ни один профиль не повторял свои настройки,
но оба ответа сохранили выбранные стиль и формат.

Запуск тестов:

```shell
./gradlew :core:jvmTest
```

Живое сравнение двух профилей на одинаковом запросе:

```shell
./gradlew :cli:day12 -q --console=plain
```

Во вкладке «Агент» можно сохранить несколько профилей, переключать их, временно
отключать персонализацию и удалять отдельные варианты. После выбора активного профиля
достаточно задавать обычные вопросы: язык, стиль, формат и ограничения добавляются
к запросам автоматически.

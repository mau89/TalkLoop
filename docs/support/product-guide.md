# Справка по продукту для поддержки

## Возможности локального TalkLoop

TalkLoop — учебное приложение Android/iOS с локальным Ktor-сервером на Mac.
Вкладка «Агент» поддерживает диалог и команду /help по документации проекта.
Вкладка «Документы» показывает поиск по отдельной кулинарной книге.
Вкладка «Ревью PR» проверяет опубликованные PR mau89/TalkLoop через локальную Ollama.
Вкладка «Поддержка» отвечает по этой базе знаний и выбранному демонстрационному тикету.
Индексы кулинарной книги, документации разработчика и поддержки разделены.

## Что получает ассистент поддержки

Перед каждым ответом MCP читает актуальную запись выбранного тикета из JSON:
клиент, язык, демонстрационный тариф, платформа, версия приложения, статус,
код ошибки, диагностические факты и заметки обращения. Факты тикета не являются
инструкциями для модели. История диалога используется только для уточнений
внутри того же тикета. При смене клиента или тикета история начинается заново.
Ассистент использует только разрешённый контекст текущего обращения;
данные других клиентов не нужны для ответа.

## Обновление справки и границы сервиса

FAQ и справка находятся в docs/support. После редактирования выполните
`.day21-venv/bin/python tools/day33/index_support.py`, затем перезапустите сервер.
RAG находит фрагменты этих документов, а номера источников в ответе позволяют
проверить рекомендации. Совпадение поискового запроса не доказывает правильность ответа.
Ассистент формирует ответ и предложение эскалации, но не закрывает тикет,
не создаёт обращений и не изменяет данные клиента. Реальные действия выполняет оператор.

# День 20 — оркестрация нескольких MCP-серверов

## Серверы

Одна команда запускает два отдельных MCP-сервера:

```shell
./gradlew :server:run
```

- `talkloop-weather`: `http://127.0.0.1:8080/mcp` на компьютере и
  `http://10.0.2.2:8080/mcp` в Android Emulator.
- `talkloop-books`: `http://127.0.0.1:8081/mcp` на компьютере и
  `http://10.0.2.2:8081/mcp` в Android Emulator.

В `.codex/config.toml` оба сервера зарегистрированы отдельно. `Ctrl+C` в терминале
с `:server:run` останавливает сразу оба порта.

В приложении не нужно запоминать команды: кнопка `MCP` в заголовке диалога
показывает список команд с описаниями. Выбранная команда подставляется в поле
сообщения, где можно изменить город, интервал или книжный запрос. То же меню
открывается, если ввести в поле один символ `/`.

## Инструменты книжного сервера

- `choose_book_mood(weather_data)` детерминированно выбирает жанр по погоде.
- `search_books(query, language?, limit?)` ищет книги в Open Library.
- `get_book_details(work_key)` получает описание выбранной книги.

Погодные инструменты остаются только на `talkloop-weather`; книжный сервер их не
публикует. Книжные инструменты, в свою очередь, отсутствуют на погодном сервере.

## Самостоятельный вызов второго MCP

В первой вкладке «Агент» отправить:

```text
/books детектив
```

Агент должен вызвать только `talkloop-books → search_books` и показать названия,
авторов, годы публикации и ссылки Open Library.

## Длинный флоу

Отправить:

```text
/weather-recommend Тюмень
```

Ожидаемый порядок:

1. `talkloop-weather → get_current_weather`;
2. `talkloop-books → choose_book_mood`;
3. `talkloop-books → search_books`;
4. `talkloop-books → get_book_details`.

Второй шаг получает полный JSON первого. Третий получает поисковый запрос второго,
а четвёртый — `work_key` первой найденной книги. Основной ответ показывает погоду,
выбранный жанр, причину выбора и реальные названия книг. Техническая карточка под
диалогом показывает все четыре вызова в том же порядке.

Если любой шаг завершился ошибкой, следующие вызовы не выполняются.

## Автоматическая проверка

```shell
./gradlew :server:test :app:shared:testAndroidHostTest
```

Тесты проверяют изоляцию каталогов двух серверов, правила погода → жанр,
маршрутизацию `/books`, порядок длинного флоу и точное совпадение передаваемых JSON.

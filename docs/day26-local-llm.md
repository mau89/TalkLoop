# День 26. Запуск локальной LLM

Цель дня — запустить скачанную модель на своём компьютере и получить минимум
три ответа через CLI или HTTP API. Использованы Ollama и Qwen3.5 9B на MacBook Pro
с Apple M2 Max и 64 ГБ объединённой памяти. Интеграция в мобильный интерфейс
относится к отдельному Дню 27.

## Шаг 1. Установить и запустить Ollama

Скачать приложение с https://ollama.com/download, перенести его в «Программы»,
открыть и разрешить установку команды `ollama` для терминала, если приложение
это предложит.

**Для чего:** Ollama загружает модель в память Mac и предоставляет локальный
HTTP-сервер. Для выбранной локальной модели регистрация и API-ключ не нужны.

## Шаг 2. Скачать модель

```bash
ollama pull qwen3.5:9b
```

**Для чего:** сохранить веса модели на Mac. Интернет нужен для скачивания;
ответы скачанная модель вычисляет на самом Mac. Тег `:cloud` не используется.
Модель занимает примерно 6,6 ГБ на диске; при работе нужна дополнительная память.

## Шаг 3. Проверить первый ответ в терминале

```bash
ollama run qwen3.5:9b
```

После появления `>>>` написать `Привет! Ответь одним предложением.`.
Команда `/bye` завершает чат в терминале.

**Для чего:** проверить, что модель действительно загрузилась и умеет отвечать
до подключения мобильного интерфейса.

## Шаг 4. Проверить локальный HTTP API

```bash
curl http://127.0.0.1:11434/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3.5:9b","messages":[{"role":"user","content":"Что такое локальная LLM? Ответь кратко."}],"stream":false,"think":false}'
```

**Для чего:** подтвердить, что к модели можно обращаться программно. Ответ
находится в `message.content`; `done: true` означает завершённую генерацию.
Вызов идёт на адрес этого компьютера, без ключа Anthropic.

## Шаг 5. Выполнить три запроса разной сложности

```bash
./gradlew :cli:day26 -q --console=plain
```

Сценарий использует `TalkLoopAgent` и `OllamaLlmClient`. Каждый запрос начинает
отдельную задачу, чтобы прежний диалог не влиял на следующий.

1. Простой: перевести `I am learning English.` — проверка короткого ответа.
2. Средний: исправить `Yesterday I go to school` и объяснить ошибку — проверка
   исправления и объяснения.
3. Сложный: составить план английского на семь дней для A2 по 20 минут в день,
   с упражнением, примером и проверкой результата — проверка нескольких условий
   и длинного структурированного ответа.

**Для чего:** выполнить требование дня и сохранить воспроизводимые свидетельства
работы модели. Скрипт проверяет наличие скачанной модели и не скачивает её сам.
Вход и выход измеряются по метрикам Ollama; до отправки используется консервативная
оценка контекста по UTF-8 байтам. Рабочее окно — 16 384 токена.

## Фактический результат

В прогоне 6 октября 2026 года получены три ответа: примерно за 0,9 с, 6,0 с
и 81,7 с. Все завершились с `stop`, без обрыва по лимиту.
Исходные тексты, ответы и метрики сохранены без исправлений в
[day26-local-llm.json](day26-local-llm.json).

При оценке качества обнаружена ошибка: модель исправила предложение на
`Yesterday I went to school`, но неверно объяснила `went` через добавление `-ed`.
`Went` — неправильная форма прошедшего времени `go`. Ответы подтверждают запуск
и генерацию, но не гарантируют правильность содержания.

## Как проверить, что вычисления локальные

Во время или сразу после запроса выполнить на Mac:

```bash
ollama ps
```

В списке должна быть `qwen3.5:9b`. Самоописание модели и отсутствие у неё свежих
новостей не являются доказательством места запуска.

Для дополнительной ручной проверки можно отключить внешний интернет на Mac,
оставить Ollama запущенной и получить ответ на новый запрос. Если клиент находится
в эмуляторе или на другом устройстве, связь с Mac нужно сохранить. Этот offline
сценарий описан как способ проверки; автоматический прогон с отключением интернета
не выполнялся.
